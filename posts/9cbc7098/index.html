RE3 单机修改器 v1.4.0：REFramework Lua 版

2026-10-19 游戏MOD / 修改器 / 生化危机3 / RE3 / REFramework / Lua

这是我写的一个《生化危机 3 重制版》单机修改器，以 REFramework Lua 脚本的形式运行——不需要编译，把一个 Lua 文件放进游戏的 reframework\autorun\ 目录，启动游戏就自动加载。

仅适用于单机离线模式。请勿用于联机、排行榜、速通认证等场景。

功能一览

功能 说明
无敌 受到攻击不掉血，生命维持在正常上限
一击必杀 敌人受伤直接放大到 99999，可随时开关
无限弹药 弹匣保持高数量，通常无需装填
无限物品 药草、手雷、弹药盒等消耗品保持 99，剧情道具不受影响
完美闪避 随时具备紧急闪避判定
游戏速度 0.10x ~ 5.00x，慢动作 / 快进
回满血量 一次性恢复到当前上限
游戏道具箱 读取游戏道具箱，把普通物品取到背包（带校验与回滚）
刷取物品 任意物品直接放入背包，未获得的也可以
刷取武器 玩家武器每次一把放入背包，刷前自动查重
中英界面 默认中文，可在界面切换

安装

  1. 安装 REFramework 的 RE3 版本（RT 显卡用 RE3.zip，非 RT 用 RE3_TDB67.zip），解压到游戏根目录。已装过的可跳过。
  2. 从 Releases 下载 re3_trainer.lua，放进游戏目录的 reframework\autorun\。
  3. 想要中文界面，在游戏根目录（re3.exe 旁边）放一个 0 字节空文件 reframework_pictographic.mode，REFramework 检测到它会使用内置中文字体。
  4. 启动游戏，日志出现 [RE3Trainer] RE3 单机修改器 ... 加载完成 即成功。

快速上手

  1. 游戏里按 Insert → Script Generated UI → RE3 单机修改器。
  2. 载入存档，顶部状态从「还没有进入游戏存档」变为「游戏中」。
  3. 勾选功能或按热键；屏幕左上角（F9）常显已开启的功能。
  4. 修改道具类数据（道具箱、刷取）之前，先按 Esc 暂停游戏，改完手动存档。

热键一览：

所有开关默认关闭，需要手动开启；设置会自动保存，下次启动保留上次状态。某个功能显示「未识别」时，按 F10 导出排查文件，或点「高级 / 排错」折叠区里的「重新识别游戏数据」。

使用注意

  • 改道具前先暂停：道具箱和刷取操作要在 Esc 暂停状态下进行，改完手动存档。
  • 备份存档：刷取钥匙、剧情道具可能卡关。存档位置在 ...\Steam\userdata\<SteamID>\952060\remote\。
  • 与 Raz0r Ultimate Trainer 二选一：两者功能重叠，同时启用容易看不出哪个生效；Auto-Dodge.lua 之类的脚本会让「无敌」开关失去意义。
  • 独立窗口的限制：F11 打开的独立窗口在 REFramework 菜单关闭时只能显示、不能点击，这是 REFramework 的输入机制决定的；按 Insert 打开菜单后即可正常交互。
  • 小刀耐久：目前只检测不修改，字段尚未确认，避免误写。

数据文件

运行后会在 reframework/data/ 下自动生成三个文件，都可以删除：

文件 内容
re3_trainer.json 开关状态、速度倍率、界面语言
re3_trainer_dump.txt F10 对象转储（排错用）
re3_trainer_itemprobe.txt 道具箱内部信息探针（只读）

已知限制

  • 联机模式不可用，修改器只在单机离线时生效。
  • 不能修改存档文件本体，不能给武器加配件——刷出来的武器是无配件、1 发弹药的状态。
  • 道具箱中的武器条目只显示，请用游戏内道具箱取出。

许可与免责

代码采用 MIT 许可证。本项目仅用于单机游戏体验优化，与 Capcom、Steam、REFramework 均无关联；使用产生的游戏内后果由使用者自行承担。遇到问题欢迎在 GitHub 提 issue，附上 F10 导出的排查文件。
