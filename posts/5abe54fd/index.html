最小的资源帖

只要在 front-matter 里加 resource 字段，普通文章就变成资源帖：

type 的取值由站点 _config.yml 里 resources.types 的 key 决定，
常见的有 movie / game / mod / translation / software / other。

完整字段

字段说明：

字段 必填 说明
enable 是 设为 true 才会进入资源库
type 是 资源类型，对应 resources.types 的 key
version 否 版本号，显示在卡片和详情表格里
platform 否 适用平台，如 Windows / Android / 全平台
size 否 文件大小
language 否 语言，如 简体中文 / 多语言
updated 否 资源更新日期，会显示在封面右上角
links 否 网盘链接数组，详见下节

网盘链接

links 是一个数组，每一项就是一张网盘卡片：

字段 说明
name 网盘名称，同时用于匹配配色
url 分享链接
password 提取码，留空则不显示复制按钮
size 该网盘内的文件大小（可与资源总大小不同）
note 备注，如「不限速」「需客户端」

几个实用技巧：

  • 多版本：同一资源的多个版本，建议每篇一个版本，用 version 区分，方便单独更新链接。
  • 多网盘：同一版本放多个网盘，全部写进 links，访客可以自己选。
  • 失效链接：直接把对应条目删掉重新发布即可，不用改正文。

网盘配色

没匹配到的网盘会使用主题主色。

资源卡片显示哪些字段

卡片上最多显示 3 个字段（避免卡片高度参差）。详情页的表格不受这个限制，
配置里出现的字段都会展示。

版权提示与密码显示

  • show_password: false 可以全局隐藏提取码（如果你用其它方式发放）。
  • notice 显示在下载区块下方，留空则不显示。
  • cover_ratio 控制封面比例，默认 16:9。

资源详情页的结构

一篇资源帖从上到下依次是：

  1. 字数 / 阅读时间 / 资源类型标签
  2. 标题与分类、标签、日期
  3. 简介（取 description 或摘要）
  4. 字段表格：版本 / 平台 / 大小 / 语言 / 更新日期
  5. 正文（安装方法、注意事项等）
  6. 下载区块：网盘卡片列表 + 提取码复制按钮
  7. 版权提示、上一篇 / 下一篇

正文里不需要再手写「版本：v3.1.4」这类信息，交给字段就好。

图标清单

resources.types[].icon 和 Hero 按钮的 icon 都从这个内置集合里取值：

图标 适用
film 影视
gamepad 游戏
puzzle MOD
language 汉化 / 多语言
app 软件工具
box 其它 / 通用
layers 资源库
archive 归档
tag / folder 标签 / 分类
download 下载
clock / calendar 时间 / 日期
file-text 文章
trending-up 统计
fire 热门
list 目录

填错名字不会报错，会回退成通用的盒子图标。
