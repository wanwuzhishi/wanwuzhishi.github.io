为什么要自己写主题

现成的 Hexo 主题大多是为「纯文字博客」设计的，而我的站点里有一大半内容是网盘资源。
资源需要的字段和文章完全不同：版本号、平台、文件大小、语言、提取码、多个网盘链接……

这些用普通文章硬凑也能写，但排版会很难看，维护起来也很痛苦。所以我干脆自己写一个主题，
让「文章」和「资源」成为两种一等公民。

资源是怎么定义的

核心思路非常简单：资源就是带有 resource 字段的文章。

只要 resource.enable 为 true，主题就会：

  1. 把它归入 /resources/ 资源库
  2. 按 type 自动进入对应分类（movie / game / mod / translation …）
  3. 在详情页渲染出网盘下载区块和复制提取码按钮
