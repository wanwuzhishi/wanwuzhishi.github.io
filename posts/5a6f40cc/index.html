Raz0r’s Ultimate Trainer 是《生化危机 3 重制版》功能最全的修改器之一，以 REFramework 插件的形式运行。原版界面是全英文的，这份汉化把 930 条界面文本完整翻译成了简体中文。

汉化覆盖主界面与全部分类、所有功能开关与选项、热键界面、通知提示、约 200 个场景传送点、物品/武器/改装件名称、敌人 ESP 名称、角色替换名称、存档槽列表和悬停帮助说明。功能逻辑与原版完全一致，只改显示文本。

安装前准备

  1. 安装 REFramework：到 REFramework-nightly Releases 下载 RE3 版本，RT 显卡用 RE3.zip，非 RT 用 RE3_TDB67.zip，解压到游戏根目录（re3.exe 所在目录）。
  2. 下载原版修改器 v2.0.3：从 Nexus Mods 或 Raz0r 的 Patreon 获取。本汉化按 v2.0.3 的字节布局制作，其他版本不保证可用。
  3. 安装 Node.js：汉化生成器是纯 JavaScript，无第三方依赖。
  4. 准备 UPX（视情况）：如果原版 DLL 是 UPX 加壳的（Nexus 下载的一般是），需要 UPX 的 win64 版，放到 PATH 或用 --upx 参数指定。

生成与安装

脚本会自动完成 UPX 解壳（如需要）→ 应用补丁 → 完整性校验 → 生成翻译对照表。输出在 dist/ 目录：

文件 说明
re3r_ultimate_trainer_zh.dll 汉化版修改器
reframework_pictographic.mode 中文显示开关（空文件）
patch_report.txt / 翻译对照表.txt 补丁报告与全部译文

然后：

  1. 关闭游戏，备份 <游戏根目录>/reframework/plugins/re3r_ultimate_trainer.dll；
  2. 把 re3r_ultimate_trainer_zh.dll 改名为 re3r_ultimate_trainer.dll，覆盖到 reframework/plugins/；
  3. 把 reframework_pictographic.mode 放到游戏根目录（和 re3.exe、dinput8.dll 同级）；
  4. 启动游戏，按 Insert 打开 REFramework 覆盖层，在 Script Generated UI 分类下就能看到「生化危机3 重制版 终极修改器」。

为什么需要那个空文件

REFramework 默认使用不含汉字的 Roboto 字体。它内置了一个面向中文玩家的隐藏机制：只要游戏根目录存在名为 reframework_pictographic.mode 的文件（内容为空即可，只检测是否存在），覆盖层字体会切换为内置的中文方正综艺体，并按完整中文字形范围渲染。

所以这个 0 字节文件不是可选项——没有它，汉化文本会显示成方块或问号。文件必须放在 re3.exe 所在目录，放进 reframework 子文件夹不会生效。

兼容性与注意事项

  • 只适用于 v2.0.3（2023-12 版）。如果游戏内提示 Unsupported Version，说明游戏或修改器版本不匹配。
  • 汉化版 DLL 是解壳后的明文 DLL，体积约 7.2 MB，比原版大属于正常现象。
  • 汉化没有改动任何内部键名，原有的 re3r_ultimate_trainer.settings 配置和已绑定的热键可以继续使用；个别条目（如 Bloom/泛光）升级后到热键界面重新绑定一次即可。
  • 「物品添加」的搜索框现在按中文关键词匹配，例如「草药」「弹药」「手枪」。
  • 以下内容按惯例保留英文：热键按键名（SHIFT、ENTER 等）、图形术语缩写（AF/AA/DOF/AO/SSR/TAA/HBAO+ 等）、引擎敌人编号（em0000 等）和引擎材质名（Metallic、Roughness、pl2000_Skin_Mat 等）。这些同时是引擎查找键，翻译会导致功能失效。

为什么仓库里没有成品 DLL

原版修改器的版权归 Raz0r 所有，通过 Nexus Mods / Patreon 分发。汉化仓库只包含自研的补丁工具链和翻译数据，不包含、也不分发原版或修改后的二进制文件。想使用汉化版的玩家，需要用自己的原版 DLL 跑一次生成脚本。

这样既避免未经授权转载二进制文件，也让汉化逻辑和译文可以被社区复用和改进。详细的逆向过程、字符串引用方式和校验方法写在这篇实践记录里。
