主题配置总览

主题自己的配置在 themes/echo/_config.yml，共分这些区块：

区块 作用
外观 配色模式、主色、圆角、整体宽度
header 内页顶部横幅
hero 首页顶部大图
menu / menu_primary 导航菜单与一级菜单
rail 左右侧栏开关与宽度
profile / music / category / tags 左栏组件
stats / toc / calendar / siteinfo 右栏组件
resource 资源字段、网盘配色、版权提示
post 文章页目录、版权、上下篇等
footer / comments 页脚与评论
code 代码块风格、复制按钮、行号

首次运行检查清单

改完配置后，按这个清单过一遍：

  • theme: echo 已设置
  • resources.types 里的 key 与文章 resource.type 对应
  • 站点 url 改成你自己的域名（影响 RSS 与站点地图）
  • 主题 profile.avatar、社交链接换成自己的
  • footer.since 改成建站年份
  • stats.since 与建站日期一致
